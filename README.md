# 간단 메모장

GitHub Pages에서 `index.html`을 열고 이메일·비밀번호로 가입합니다. 로그인 후 메모를 저장하거나 삭제할 수 있습니다.

Supabase의 `memos` 테이블을 사용하며, 로그인한 사용자 본인의 메모만 조회·추가·삭제하도록 RLS를 적용했습니다. 프런트엔드에는 공개용 키만 사용합니다.

접속: https://lsunbog.github.io/simple-memo/

검증(2026-11-01): 배포 사이트 접속, 회원가입 직후 자동 로그인, 메모 저장·목록 표시, 새로고침 후 로그인·메모 유지, 삭제, 로그아웃·재로그인 통과. HTML 태그도 일반 텍스트로 표시됩니다. RLS 활성화 및 본인 조회·추가·삭제 정책을 확인했고, 다른 사용자 ID로 조회·삭제 시 접근 가능한 행은 0건이었습니다.
